# HKBEES by HK Group

Plateforme professionnelle de gestion apicole destinée aux apiculteurs, exploitations, techniciens et organisations internationales.

## État du dépôt

Le dépôt contient un prototype historique React/FastAPI conservé pour audit et reprise. La refonte HKBEES est préparée sur la branche `hkbees/foundation` avant toute migration de la branche principale.

- `frontend/` : prototype Web existant.
- `backend/` : prototype API FastAPI existant.
- `docs/HKBEES-FOUNDATION.md` : architecture cible et stratégie de migration.
- `infra/hostinger/README.md` : cible de déploiement sur le VPS Hostinger de HK Group.
